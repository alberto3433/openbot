How Menu Display Groups Work

Menu Display Groups consolidate item types into user-friendly categories for menu listing. When a user asks "what's on your menu?", we show these groups instead of 25+ granular item types.

Display Order: Lower numbers appear first in the menu listing.

Name: The display name shown to users (e.g., "Breads", "Sandwiches", "Omelettes and Breakfasts").

Slug: Unique identifier used internally (e.g., "breads", "sandwiches").

Parent Group: Sets up a hierarchy. E.g., set "Candy Bars" parent to "Snacks" so that asking "what snacks do you have?" also shows candy bars. Child groups are hidden from the top-level "what do you have?" listing.

Aliases: Alternative names users can say to reference this group. E.g., "desserts_pastries" can have aliases like "pastries", "pastry", "sweets". When a user says "pastries", we'll show items from this group.

Item Types: The number of item types assigned to this group. Assign item types via the Item Types admin page.

Note: You cannot delete a group that has item types assigned to it. First reassign or remove item types from the group.
