How Response Patterns Work

Pattern: The phrase to match in user input (e.g., "yes", "no thanks"). Matched case-insensitively.

Types:

  • Affirmative: Yes responses (yes, yeah, sure, ok, yep, absolutely, etc.)
  • Negative: No responses (no, nope, nah, no thanks, etc.)
  • Cancel: Cancel intent (cancel, never mind, forget it, start over, etc.)
  • Done: Order complete intent (that's all, that's it, nothing else, I'm good, etc.)

These patterns help the bot recognize user intent when answering yes/no questions or indicating they're done ordering.
