How Ingredient Categories Work

Slug: Unique identifier used in code (e.g., "protein", "topping", "milk"). Must be lowercase with no spaces.

Display Name: Human-readable name shown in the UI (e.g., "Proteins", "Toppings", "Milk Options").

Modifier Type: How this category is used in the ordering system:

  • Food: Modifiers for food items (bagels, sandwiches, omelettes). Examples: protein, topping, sauce, cheese, spread.
  • Beverage: Modifiers for beverages (coffee, tea). Examples: milk, sweetener, syrup.
  • None: Not a modifier category (used for item types, not customizations). Example: bread.

Display Order: Controls the order categories appear in the UI. Lower numbers appear first.
