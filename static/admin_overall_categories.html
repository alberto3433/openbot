How Menu Item Categories Work

Categories are high-level classifications for menu items. They enable generic search requests like "I want a drink" to return all items in the "drink" category.

Name: Display name shown in the UI (e.g., "Drink", "Food").

Slug: Unique identifier used for search matching (e.g., "drink", "food"). This is what users type to search by category.

Description: Optional explanation of what items belong in this category.

Menu Items: A menu item can belong to multiple categories. Assign categories in the Menu Item edit screen.
